title: Отправка наставником приглашения студенту в проект
---

## Предусловия:

* пользователь авторизован как «сотрудник».

* у пользователя есть проект, в который он может приглашать студентов.

* в проекте есть свободные места.

* в системе есть студент, которого можно пригласить в проект.

## Шаги:

1. Пользователь открывает раздел "Мои заявки".

2. Пользователь открывает проект со статусом "Одобрено".

3. Пользователь переходит на страницу «Список приглашений».

4. Пользователь нажимает кнопку «Пригласить участников».

5. В открывшемся окне пользователь выбирает институт.

6. Пользователь выбирает необходимую группу.

7. Пользователь выбирает студента, доступного для приглашения.

8. Пользователь нажимает кнопку «Отправить приглашение».

## Ожидаемый результат:

Система отправляет выбранному студенту приглашение в проект.

Отправленное приглашение отображается в списке приглашений со статусом «Ожидает ответа».

Система отправляет выбранному студенту уведомление о приглашении в проект.
