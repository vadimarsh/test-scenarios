title: Просмотр наставником статуса отправленных приглашений
---

## Предусловия:

* пользователь авторизован как «сотрудник».

* у пользователя есть проект, в который были отправлены приглашения студентам.

## Шаги:

1. Пользователь открывает раздел "Мои заявки".

2. Пользователь открывает проект со статусом "Одобрено".

3. Пользователь переходит на страницу «Список приглашений».

4. Система загружает список отправленных приглашений.

5. Пользователь просматривает список приглашений.

## Ожидаемый результат:

Пользователь видит таблицу приглашений с указанием ФИО студента, группы и статуса приглашения.

Для приглашений со статусом «Ожидает ответа» отображается кнопка «Отменить».
